# FolhaCerta

Aplicativo web (PWA) para importar espelhos de ponto PDF textuais, identificar horas e estimar salário.

## Publicação pelo GitHub Pages

1. Abra **Settings → Pages** do repositório.
2. Em **Build and deployment** selecione **Deploy from a branch**.
3. Escolha **main**, pasta **/(root)** e clique **Save**.
4. Quando a publicação for concluída, abra **https://cassiano-gualberto.github.io/folhacerta/** no Chrome do Android.
5. Use o menu do Chrome **Adicionar à tela inicial** ou **Instalar aplicativo**, quando disponível.

## Privacidade
- Os arquivos PDF são lidos localmente no navegador. Não são enviados a servidor.
- Não publique PDFs de ponto nem contracheques no repositório.
- Os valores do salário são configuráveis e ficam no dispositivo, em armazenamento local.
- O repositório traz apenas salário fictício de exemplo.

> Os resultados são estimativas e podem divergir da folha oficial, especialmente no DSR e em rubricas excepcionais.
